# Security policy

## Supported version

Only the latest commit on the default branch is maintained.

## Reporting a vulnerability

Use this repository's **Security → Report a vulnerability** flow. Do not open a public issue for a security or privacy vulnerability.

Never attach signing certificates, provisioning profiles, Apple account information, real coordinates, raw location history, or device logs containing personal information.

## Scope

Security-sensitive areas include local location storage, notification action routing, background region monitoring, Watch handoff behavior, and accidental inclusion of personal or signing metadata in the repository.

This project has no server, account system, analytics backend, or remote data store.
