# Contributing

Thank you for helping improve Never Miss Golf.

## Before opening an issue

- Search existing issues.
- Remove real course names, coordinates, location history, home or school details, device identifiers, signing information, and personal screenshots.
- Describe OS versions, permission state, and expected versus observed behavior without publishing private data.
- Do not report simulated behavior as a real-device result.

## Pull requests

1. Keep changes small and explain the product or privacy reason.
2. Run `scripts/validate_project.ps1` and `scripts/scan_public_release.ps1`.
3. Run the Xcode tests when a Mac is available.
4. Do not add accounts, servers, analytics, advertising, HealthKit, continuous location history, or automatic workout start without a separate proposal and threat review.
5. Do not add generated media or copied assets unless their license and provenance are documented.

By contributing, you agree that your contribution is licensed under Apache-2.0. GitHub will display the identity attached to your own account and commits; use GitHub's privacy controls and a no-reply email if that matters to you.
